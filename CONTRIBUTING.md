# Contributing to mcp-server

Use pnpm 10 and Node.js 18 or newer. Install dependencies with `pnpm install`,
run `pnpm build`, `pnpm types:check` when available, and `pnpm test`.
Add a changeset for every published behavior change with `pnpm changeset`.

The release workflow creates the version PR and publishes only after that PR is
merged into `main`.
